STAGE 01 — PHISHING

10:14 AM — Sahithi Receives a Message

Sahithi is working normally when an unexpected account verification message appears on her screen. The message creates urgency and asks her to take immediate action.

From: IT Support — MedCore
To: Sahithi
Subject: URGENT: Account Verification Required

Hello Sahithi,


Your MedCore account requires immediate verification to prevent temporary suspension.


Please verify your account using the button below.

VERIFY ACCOUNT


Regards,
IT Support

🔍 Security Analysis

⚠ Urgency: The message tries to make the employee act quickly.
⚠ Unexpected request: Sahithi did not request an account verification.
⚠ Sender verification: The sender should be verified before trusting the message.
✓ Correct response: Verify through an official channel instead of blindly following the message.
🧠 What is phishing?

Phishing is a social-engineering technique where an attacker creates a deceptive message to trick a person into performing an unsafe action.

Why is it dangerous?

A successful phishing attempt can become an initial entry point into an organization's environment.

🛡️ Defender lesson:

Stop. Verify the sender. Check the request through an official channel. Report suspicious messages instead of interacting with them.
