⚙️ What is Execution?

Execution is the stage where an attacker attempts to make code, a program, script, or other action run on a compromised system.

💡 Simple example:

Getting inside a building is like Initial Access.

Trying to operate something after entering is like Execution.

Imagine a hospital employee interacts with a malicious document and an unauthorized program attempts to run.

That activity could become a stepping stone for additional attacker actions.

🛡️ How Can Defenders Detect Execution?

✓ Monitor unusual processes and applications
✓ Use endpoint detection and response (EDR)
✓ Restrict unnecessary script execution
✓ Investigate suspicious process behaviour
✓ Maintain security logs for investigation

🧠 Key Lesson

Initial Access = the attacker gets in.

Execution = the attacker tries to make something happen inside the environment.

Detecting suspicious execution early can prevent the attack from progressing to later stages.
